1. Resumo do FitFolio

Onboarding/Questionário: Fluxo step-by-step com telas modulares (idade, peso, altura, nível de atividade, objetivo, restrições). Barra de progresso no topo e navegação direta com coleta mínima inicial.


Telas principais: Dashboard centralizado com estatísticas diárias (macros, calorias, streaks). Tela de treino categorizada por grupos musculares com guias. Tela de dieta com registro por refeição em tempo real.


Destaques visuais: Cards arredondados estilo glass, anéis de progresso circulares estilo Apple Watch, iconografia limpa e acentos coloridos sobre tema escuro.

2. Especificação Funcional

  • Onboarding & Questionário: 8-10 etapas para mapear corpo, meta (hipertrofia/definição/emagrecimento/força), restrições alimentares e equipamentos.
  • Dashboard: Resumo diário de consumo calórico, progresso dos macros, registro de água e atalho para o próximo treino.
  • Módulo de Treino & Treino ao Vivo: Split semanal com timer de descanso regressivo, ajuste de carga em tempo real e progresso por séries.
  • Módulo de Dieta: Plano nutricional dividido em refeições com busca rápida de alimentos da Tabela TACO.
  • Perfil & Progresso: Histórico de peso, recálculo de plano e configurações de notificações.

4. Stack Técnica Recomendada

Camada Tecnologia Justificativa
Mobile React Native + Expo Base única para iOS e Android, ecossistema maduro, compilação nativa.
Web Next.js 15 SSR de alta performance, SEO otimizado e mesmo idioma do mobile.
Backend Supabase Edge Functions Serverless em TypeScript, resposta rápida de baixa latência e integração nativa.
Banco de Dados PostgreSQL Relacional, robusto, com busca fuzzy (`pg_trgm`) e Row Level Security (RLS).
Inteligência Artificial Claude API (Anthropic) Geração estruturada (JSON mode) de treinos e dietas personalizadas sem alucinações.
Base de Alimentos Tabela TACO (UNICAMP) Padrão ouro brasileiro com mais de 600 alimentos nacionais categorizados.

5. Design System — Liquid Glass
